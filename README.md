# 林畅 · 个人作品集

一个个人作品集单页网站，展示个人介绍、技能方向与项目作品。使用原生 HTML、CSS 和 JavaScript 开发，不依赖任何前端框架或第三方 UI 组件库。

## 项目功能

- **单页作品集结构**：左侧侧栏承载个人介绍、站内导航、技能标签与联系方式；右侧主内容区依次为 Hero 介绍、项目作品、关于我、联系方式四个区块。
- **数据驱动渲染**：所有个人资料与项目数据集中在 `js/data.js`，页面由 `js/main.js` 渲染生成。新增项目只需往 `PROJECTS` 数组追加一个对象，页面自动生成新条目，无需改动 HTML。
- **项目作品杂志式排版**：项目条目采用纵向排列、图文左右交替（zigzag）的杂志式布局；鼠标悬停时项目标题变强调色、预览图轻微放大。
- **滚动导航高亮**：页面监听滚动，以视口 35% 高度处作为当前阅读位置，自动高亮左侧对应的导航项（项目作品 / 关于我 / 联系方式）。页面同时启用了平滑滚动，并预留 `scroll-padding-top` 避免锚点被顶部栏遮挡。
- **深浅色主题切换**：侧栏头部右上角提供主题切换按钮（移动端位于汉堡按钮左侧），支持浅色 / 深色主题切换，页面主要背景、文字与边框颜色同步变化，按钮图标在月亮与太阳之间切换。
- **主题记忆**：用户的选择保存在 `localStorage`（键名 `portfolio-theme`），刷新或再次访问时自动应用上一次的主题；未设置过时默认使用浅色。
- **移动端折叠导航**：窄屏下侧栏收起为顶部固定栏，通过汉堡按钮展开 / 收起导航菜单，点击导航链接后菜单自动收起。

## 技术栈

| 类别 | 说明 |
| --- | --- |
| 页面结构 | HTML5 语义化标签（`aside` / `main` / `section` / `header` / `footer`） |
| 样式 | 原生 CSS3：CSS 自定义属性（变量）、Grid、Flexbox、媒体查询、过渡动画 |
| 脚本 | 原生 JavaScript（无框架、无构建工具、无 npm 依赖） |
| 字体 | Google Fonts 的 Noto Serif SC（标题衬线字体） |
| 预览图 | 通过 `text_to_image` 接口按项目描述自动生成，可在数据中指定 `image` 字段覆盖为本地截图 |

设计上把配色抽成了 `:root` 中的 CSS 变量（`--bg-light`、`--ink`、`--ink-soft`、`--line`、`--accent` 等），深色主题通过 `[data-theme="dark"]` 覆盖同一组变量实现，因此切换主题不需要改动任何结构代码。

## 响应式布局

页面按两档断点适配桌面端与移动端：

- **桌面端（> 960px）**：`.layout` 使用 `grid-template-columns: 330px 1fr`，左侧为 `position: sticky` 的固定侧栏，随页面滚动保持可见；右侧主内容区居中，最大宽度 1120px，左右内边距随视口自适应（`clamp(24px, 5vw, 72px)`）。
- **移动端 / 平板（≤ 960px）**：布局改为单列上下结构。侧栏收起为顶部固定栏（高 64px），仅保留头像与姓名，导航、技能与联系方式折叠进汉堡菜单；项目条目由左右交替网格改为纵向堆叠（元信息横排、预览图居中占半宽）；关于我由双列改为单列；联系按钮撑满整行。
- **小屏（≤ 420px）**：进一步精简顶栏，隐藏标语文字，并收窄 Hero 统计数字的间距。

## 本地运行

项目为纯静态页面，无需构建或安装依赖，用浏览器直接打开 `index.html` 即可。如果希望通过本地服务器访问：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 如何新增一个项目

在 `js/data.js` 的 `PROJECTS` 数组中追加一个对象即可：

```javascript
{
  title: "项目名称",
  desc: "项目简介",
  stack: ["技术", "标签"],
  date: "2026.10",
  category: "类别",
  link: "https://项目链接",
  imagePrompt: "用于生成预览图的画面描述"
}
```

如需使用本地截图，额外添加 `image: "assets/project-xx.jpg"` 字段即可覆盖自动生成的预览图。
